# VELQORA CAD — установщик и обновления

VELQORA CAD — программа для Windows: раскрой, карты присадки, деталировка, сборочные чертежи, смета и база материалов по мебельной модели из «БАЗИС-Мебельщика».

## Как установить

1. Откройте [страницу выпусков](https://github.com/MatrixMind2026/bazisreborn-updates/releases/latest).
2. Скачайте файл **VelqoraCAD-Setup-&lt;версия&gt;.exe** (файл `VelqoraCAD.update.json` скачивать не нужно — его читает сама программа).
3. Запустите установщик. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
4. Укажите папку скриптов БАЗИСа — установщик положит туда скрипт выгрузки.

## Обновления

Программа сама проверяет эту страницу при запуске и предлагает установить новую версию. Перед установкой программа сверяет размер файла и SHA-256 с описанием выпуска.

При обновлении с прежнего названия текущая папка программы сохраняется. При первом запуске импортируются настройки, база и прайсы. Файлы проектов остаются на своих местах. В выпуске дополнительно лежат два файла со старым именем для автообновления прежних установок.
