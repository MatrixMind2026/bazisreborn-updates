# BazisReborn — установщик и обновления

BazisReborn — программа для Windows: раскрой, карты присадки, деталировка, сборочные чертежи, смета и база материалов по мебельной модели из «БАЗИС-Мебельщика».

## Как установить

1. Откройте [страницу выпусков](https://github.com/MatrixMind2026/bazisreborn-updates/releases/latest).
2. Скачайте файл **BazisReborn-Setup-&lt;версия&gt;.exe** (файл `BazisReborn.update.json` скачивать не нужно — его читает сама программа).
3. Запустите установщик. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
4. Укажите папку скриптов БАЗИСа — установщик положит туда скрипт выгрузки.

## Обновления

Программа сама проверяет эту страницу при запуске и предлагает установить новую версию. Каждая версия подписана автором: изменённый или чужой файл программа не установит.

Если у вас стоит прежняя тестовая версия — один раз скачайте установщик отсюда и поставьте поверх. Настройки, цены и проекты сохраняются.
